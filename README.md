# gpt2-from-scratch

Character-level GPT-2 implemented in PyTorch, following the architecture in
Andrej Karpathy's "Let's build GPT" lecture and nanoGPT.

- `gpt_1.py`: first version (attention and MLP blocks)
- `gpt_2.py`: full model and training loop
- `tokeniser.py`: BPE tokenizer

Built Jul–Oct 2026, uploaded Oct 2026.

## Running

pip install torch
python gpt_2.py
